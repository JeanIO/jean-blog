# 项目规范

1. controller 层负责处理路由请求，做相关的输入参数校验后调用业务逻辑层处理业务逻辑，最后返回响应结果。
2. model 层定义了数据模型，用于表示数据库中的表结构。

## routes 层

routes 层负责定义路由，将请求映射到对应的 controller 层方法。
在本项目中，routes 层分为 back-stage 和 client 两个部分。
back-stage 部分负责处理后台管理相关的路由，如用户管理、服务管理、博客管理等。
client 部分负责处理客户端相关的路由，如用户登录、注册、博客列表、博客详情等。
service 部分负责处理公共服务相关的路由，如获取 COS 授权、上传文件到 COS 等。
